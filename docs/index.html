delegateH

Use Hydrogen in Gemini Tasks when it’s missing from Antigravity.

On a promotional or trial Google AI Pro plan, check the model picker in Gemini for Mac. If Task mode offers 4 Hydrogen, delegateH can hand off work from Codex using your existing plan.

Check your plan in Gemini Tasks

Google excludes some Antigravity models from free trials. Gemini Tasks has its own model picker, and access can vary by account. In one test, Antigravity’s CLI and ACP catalogs omitted Hydrogen while Gemini for Mac completed a task and reported Used 4 Hydrogen model. Antigravity plan FAQ · Gemini model availability

Setup

The workaround uses your signed-in Gemini account on macOS.

  1. Check your worker model in Gemini Tasks

    Install Gemini for Mac and sign in with the Google account that has your plan. Open a new conversation, choose Task, and look for your preferred worker. To run Hydrogen, check that 4 Hydrogen appears. Complete Tasks onboarding if prompted. Download Gemini · Google’s Tasks setup guide

  2. Install the Codex skill

    From a fresh Git checkout, copy the skill folder into Codex’s user skills directory. If you already have delegateH installed, review your local changes before updating it.

    Shell
    git clone https://github.com/HighTierRoach/delegateH.git
cd delegateH
mkdir -p "$HOME/.agents/skills"
test ! -e "$HOME/.agents/skills/delegateH" &&
  cp -R delegateH "$HOME/.agents/skills/"

  3. Verify a response

    Submit a simple task such as Compute 12 + 7. After it completes, open the response’s More actions menu and check the Used … model entry. Live tests confirmed both 4 Hydrogen and 4 Argon.

Usage

Choose your orchestrator in Codex and your worker in Gemini Tasks.

Choose your models

Select your orchestrator in the Codex model picker before pasting the prompt. From the CLI, use codex -m <model-id>.

Use a model shown in your Gemini Task picker. The default is 4 Hydrogen. Tasks use the allowance of your signed-in Gemini plan.

Codex prompt
$delegateH AUTO Use 4 Hydrogen as the Gemini Tasks worker. Review this change and delegate independent checks if useful.
AUTO
Let Codex decide whether to delegate.
BUILD
Request proposed changes for independent pieces.
DEBUG
Investigate different causes in parallel.
AUDIT
Review for correctness, reliability, or performance.
TEST
Find gaps and propose regression coverage.
RESEARCH
Assess sources and evidence independently.

The skill uses up to three independent tasks by default. Codex hands off scoped prompts through the Mac app when computer use is available. You can also submit those prompts manually. Codex reviews proposed changes and runs the project checks.
