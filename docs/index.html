Setup

Use the Gemini app and your signed-in Google AI plan.

  1. Prepare Codex and Gemini

    Install Git and the official Gemini app for Mac. Select GPT-6.1 Sol in Codex and sign in to Gemini with your personal Google AI Pro account. Download Gemini.

  2. Install the Codex skill

    From a fresh checkout, copy the skill folder into Codex’s user skills directory. If you already have delegateH installed, review your local changes before updating it.

    Shell
    git clone https://github.com/HighTierRoach/delegateH.git
cd delegateH
mkdir -p "$HOME/.agents/skills"
test ! -e "$HOME/.agents/skills/delegateH" &&
  cp -R delegateH "$HOME/.agents/skills/"

  3. Check Gemini Tasks access

    In a new Gemini conversation, choose Task and check that the model picker offers 4 Hydrogen. Complete Tasks onboarding if prompted. Google’s Tasks setup guide.

Usage

Invoke the skill in a Codex session with Sol selected.

Codex prompt
$delegateH AUTO review this change and delegate independent checks if useful.
AUTO
Let Sol decide whether to delegate.
BUILD
Request proposed changes for independent pieces.
DEBUG
Investigate different causes in parallel.
AUDIT
Review for correctness, reliability, or performance.
TEST
Find gaps and propose regression coverage.
RESEARCH
Assess sources and evidence independently.

The skill uses up to three independent tasks by default. Codex hands off scoped prompts through the Mac app when computer use is available. You can also submit those prompts manually. Sol reviews proposed changes and runs the project checks.
