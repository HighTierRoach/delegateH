Verification status

Codex discovery and the local dispatcher were tested on macOS, including three concurrent fixture workers. The signed-in Antigravity CLI and ACP catalogs both omitted Hydrogen during testing, so live inference and concurrency remain unverified.

Setup

Tested on macOS. The dispatcher uses Python’s standard library.

  1. Prepare Codex and Antigravity

    Install Python 3.9 or newer, Git, and the official Antigravity CLI. Select GPT-6.1 Sol in Codex. Launch agy and sign in with your personal Google AI Pro account. The runner also looks for ~/.local/bin/agy.

    Worker requests use included Antigravity quota. The runner excludes Gemini API keys and Cloud ADC environment settings, and disables credit overages for each run.

  2. Install the Codex skill

    From a fresh checkout, copy the skill folder into Codex’s user skills directory. If you already have delegateH installed, review your local changes before updating it.

    Shell
    git clone https://github.com/HighTierRoach/delegateH.git
cd delegateH
mkdir -p "$HOME/.agents/skills"
test ! -e "$HOME/.agents/skills/delegateH" &&
  cp -R delegateH "$HOME/.agents/skills/"

  3. Check model access

    Shell
    runner="$HOME/.agents/skills/delegateH/scripts/orchestrator.py"
python3 "$runner" healthcheck

    listed means the pinned Hydrogen model appears in your account catalog. Run python3 "$runner" healthcheck --probe to check a live response. If you see model_unavailable, check agy models and your Antigravity plan and model access.

    Run python3 "$runner" healthcheck --acp to inspect the official Antigravity ACP session catalog without submitting a prompt.

Usage

Invoke the skill in a Codex session with Sol selected.

Codex prompt
$delegateH AUTO review this change and delegate independent checks if useful.
AUTO
Let Sol decide whether to delegate.
BUILD
Split implementation across distinct files.
DEBUG
Investigate different causes in parallel.
AUDIT
Review for correctness, reliability, or performance.
TEST
Find gaps and propose regression coverage.
RESEARCH
Assess sources and evidence independently.

The skill defaults to three workers and caps a round at five. Each worker gets an isolated snapshot of the committed files you select. Keep secrets out of prompts and shared files. Sol reviews patches and runs the project checks before integration.
